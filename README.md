# 📊 Excel Sales Performance Dashboard

## 📌 Project Overview

An interactive Excel dashboard built using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

## 📷 Dashboard Preview

![Dashboard Preview](Dashboard.png)

## ✨ Features

- KPI Cards
- Pivot Tables
- Pivot Charts
- Slicers
- Sales by Region
- Monthly Sales Trend
- Profit Analysis
- Payment Mode Analysis
- Salesperson Performance

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

## 📈 KPIs

- Total Sales
- Total Profit
- Total Orders
- Average Sales
- Profit Margin
